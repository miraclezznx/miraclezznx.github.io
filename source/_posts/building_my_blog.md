## 第一次做的项目

记得是今年上半年，跟随舍友与同学参与了计算机设计大赛，那是我第一次上手做网站的项目。那时候用的 AI 还是我权威的「豆姐」，我在豆姐的帮助下搭建环境，用 VSCode 和 IDEA 做前端与后端。那时候也是啥也不懂，全程跟着豆姐一步一步做出了简陋的网站。

后来出现了问题，网站的登录与注册始终出现问题，不管是怎么提示豆姐，她总是在那里来来回回让我改来改去，却依旧无济于事。但临近结束期限，只好打包给队长，让他去完成这个任务。

可我至今还记得在本地测试成功的兴奋，还有解决登录与注册问题时啥也不懂的手足无措。自那以后好像就对搭建网站祛魅了，一直处于摆烂的状态直到大二……

## 做个人博客的动机

起因是舍友 colin 搭建了自己的博客，他向我分享了他搭建博客用的框架，还有那种看到自己网站在公网上挂着、与各种师傅互挂友链、为了研究某一个板块功能熬夜查资料的各种经历。起初我真的不以为意，甚至觉得自己的文采也不好，搭建了博客也不知道写什么，还有自己这个摆烂生活，记录这些有什么意义呢？我也就一而再再而三地拖欠，始终是一种不冷不热的态度。

然而在 colin 源源不断的影响下，看到他找导师、汇报论文、参加各种比赛、反复打磨自己的本领，而自己却一直像个咸鱼，学习算法也是三天打鱼两天晒网。在这种对比之下，人家还反复拉着我去做科研，给予我各种建议，我真的觉得我要做出改变，于是决定从当下做起，先搭建一个个人博客，再学习算法吧。虽然还是无法超越人家，但是进步了就好。

## 做个人博客的收获

从前我也是从来不关注外界的变化，当前 AI Agent 的发展等等，尤其是 ChatGPT 付费版，总觉得对 AI 的付出是无用功，让 AI 帮我们工作好像就是我问一个问题，然后 AI 为你解决，我也学不到什么。可是 colin 一直在利用 AI，利用它来整理文献、修正思绪，并不断进步。反观我既不利用 AI，也没有使用身边现有的资源来进步。

直到 colin 再次提出让我搭建博客，我也决定不再原地踏步与摆烂了，开始了这次搭建博客。依旧是 AI 开局，因为还是什么也不懂，这次换了一个 AI，开始用了 GPT，让 AI 开始教我配环境、下载 Hexo 和 Butterfly。AI 教我用 CMD 下载东西，用了这么久的 CMD，也是记住了从 C 盘换到 D 盘的 `cd` 指令，也记住了本地网页启动的流程 `hexo g` 和 `hexo s`，还有 VSCode 各种文件的意义。

后来就是把 GitHub 当作仓库，利用 Git 更新仓库并上推公网，并购买了自己的首个域名 s1r1us.top。因为 sirius.com 没有了，然后忘了考虑 s1r1us.com，直接整了个 top，也算是一个小疏忽了。在上推公网之前，我也修改了自己的背景，改成了星空背景，希望自己看到这片星空，能够沉下心来学习。

后来发现自己的页脚出现了问题，用 GPT 始终无法修改。后来室友 colin 建议我试试 Harness，真是一试就上头了，感觉自己不会思考了，好像就是输入提示词，然后 DSH 就帮我把文件改好了，感觉很酷，于是好像就沉迷上这种感觉了。当我当天晚上向室友分享这份喜悦时，他也劝我应该自己去查资料，去研究这个是怎么实现的。回视我这个做博客的经历，我始终就是出现了瓶颈就向 AI 求助，也没有研究具体是怎么实现的，这也确实是我的问题。希望在日后的博客改进中不会出现这种过度依赖 AI 的现象了。

还有在不断更新网站的时候，因为我是每改一点就会上推，导致自己也对这种 CMD 命令行比较熟悉，比如 `git add .` 和 `git push` 等等。说实话，在网站开发的过程中，确实再次感受到了开发的多巴胺，希望这篇博客能够督促我继续坚持下去，就像我头像下的那句话：keep moving……

## 本人博客开发的具体流程

我也想让更多人去开发个人博客，就像当初 colin 那样一遍一遍地鼓励我，我才开始了这次搭建。个人博客搭建过程：

1. 搭建博客框架：在 Windows 上使用 Hexo + Butterfly 搭建个人博客。
2. 主题配置：修改博客名称、头像、背景、导航栏、分类、标签等，逐步完成博客的个性化设计。
3. Git 与 GitHub：使用 Git 管理博客源码，并将项目上传到 GitHub，实现版本管理。
4. 网站部署：通过 GitHub Pages 部署博客，使网站能够在公网访问。
5. 域名配置：使用 Cloudflare 接入自定义域名 s1r1us.top，完成 DNS、HTTPS 等配置。
6. 网站优化：配置 Cloudflare 的缓存、Always Online、Bot 防护等功能，提高网站的稳定性和安全性。
7. 后续完善：继续添加友链、文章、分类、标签等功能，不断完善个人博客。
